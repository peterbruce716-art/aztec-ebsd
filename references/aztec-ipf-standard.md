# 本用户的 MTEX CPR/CTF IPF 显示与数据保真标准

> 历史工作区记录，仅供追溯；其中外部脚本路径、CTF 依赖和“公开原生接口”措辞不代表本包当前能力或厂商支持的公共 SDK；当前入口及版本绑定边界以 [SKILL.md](../SKILL.md) 和 [原生工具链规范](aztec-native-toolchain.md) 为准。

本规范来自用户要求以后沿用已验证的 AZtecCrystal 显示效果。适用于本用户的 CPR/CTF IPF 工作；用户明确指定其他方向、色键或图层时按其要求执行。KAM、GOS、相图等使用各自的物理量与图例，不能套用 IPF 色键。

## 默认显示

- 图层：BC + 逐测点 IPF + GB。IPF 方向为样品 Z0，参照系为 CS0。确认源数据轴与空间坐标约定后实现此方向，不盲目翻转、交换轴或旋转 Euler 角。
- 保留各相的晶体对称性、相编号与名称对应关系、原始点序、网格和步长。CPR 必须具有可读取的配套 CRC 或可验证的等价测量数据；仅有项目头不能视为包含取向数据。
- 同相、已解析相邻点的最小错配角：`2° <= angle <= 10°` 灰色 RGB(128,128,128)，`angle > 10°` 黑色。未启用额外相界图层时，不把全部相界自动画成这两类晶界。
- BC 显示上下限、透明度与可见图层以当前数据和原生配置为准并记录。Map_006 的 21–249 不是所有文件的固定范围，也不保证其他项目采用数据最小/最大值作为显示限值。
- 保留逐点取向变化；常规 IPF 渲染不默认执行晶粒平均着色、晶粒重构、删小晶粒、形貌平滑或插值补洞。未解析测点在此叠加方式中显示 BC 灰度，地图背景颜色不等于未解析点颜色。
- 比较前后图时统一视野、方向、色键、BC 范围、透明度、倍率与线宽。放大导出不增加测量分辨率。图例标明方向、晶界阈值与尺度；晶界长度占比要用实际长度和所声明的校正规则，不用边界段计数冒充长度比例。

## 精确色彩匹配的依赖和验证

已验证方法：MTEX 从实际测量文件读取相与取向，独立计算邻接几何和错配角；本机 AZtec 公开原生接口提供该数据集的逐点 IPF 色键值；MATLAB 独立完成 BC 混合与边界绘制。原生最终地图只作为绘制完成后的验证参照，不得充当复现输出底图或从截图取色。

这依赖已安装的 AZtec，不能称为纯 MTEX 默认色键的等价实现。MTEX 默认 HKL、TSL、HSV 色键在 Map_006 上均有色差。如果用户要求纯 MTEX，明确使用的色键与未满足的原生精确匹配条件，不隐瞒替代方案。

任何新输入，包括降噪/补点后的输入，都要从其最终相与取向重新生成原生色键及验证参照，并核对源文件哈希/数据身份。不能将原始 IPF 颜色贴到已处理数据上。现有标准入口支持直接导入独立 CTF；CPR 路径需要同名配套 CRC 和 CTF。相编号、点序、坐标和实际取向必须绑定同一份输入，不能只凭文件名或网格尺寸判断配套正确。当前实现逐点比较原生与 MTEX 取向（最大容许文本精度差 0.00025°），同时检查相数、Laue 群、空间群、晶格参数和 CTF 的 CS0 约定。

验收覆盖真实测量点序、坐标和相映射、邻接错配角分类、BC 混合，以及导出 PNG/TIFF 后回读的像素比较。报告比较尺寸、倍率、线宽、软件版本和差异数量。精确像素一致只有实际验证通过才可声称；截图缩放/抗锯齿和带标尺 FIG 的图形栅格化是另外的显示范围。

## 降噪、补点与接近原始数据

处理写入新的输出路径，保留原始 CPR/CRC/CTF。先报告原始已解析数、未解析数、相分布、网格和步长。降噪方法及参数应依据数据评估，以同相邻域和晶界约束避免跨晶界抹平；不能仅为了看起来整齐而大幅改变真实细晶结构。

用户要求无未解析点时，可以在授权派生数据中估计补齐，但必须保留原始未解析掩膜、所有改变点掩膜及补点方法/范围。不要把补点后 phase > 0 解释为实验索引率提高，也不要伪造 BC、MAD、Bands 等测量质量字段。报告不确定性较大的大孔洞、跨相区域或远离有效邻域的补点；无法保证这些估计就是真实原取向。

“接近原始”用可复查数字验收，分别统计：

1. 原本已解析位置：在晶体对称性下计算处理前后取向错配角，报告中位数、P95、P99、最大值及超过所选容差的数量；容差需依据当前任务说明。核对这些位置的相标签是否改变。
2. 原本未解析位置：报告填充数量、占比、相归属和估计来源/邻域距离或其他实际采用的可信度指标；这些点没有原始测量取向，不能纳入“与原始误差很小”的取向误差统计。
3. 空间结构：核对点数、坐标、网格、步长；比较同相 LAGB/HAGB 长度、边界位置与变化图。只有实际开展晶粒分析时才比较按相同重构阈值计算的粒径/晶粒数量，不为显示本身额外改变形貌。
4. 输出读回：检查有效相、有限取向和所选字段；验证请求的零剩余未解析数量。导出 CPR 时同时提供实际配套 CRC，并与 CTF 读回对照点数、相、坐标和取向（允许已声明的文本精度舍入）。记录源哈希未变。

若输出 KAM，声明邻域与错配角截止值，并区分包含估计点与仅原测量支持的统计。平滑通常会降低 KAM；不能将处理导致的降低解释为再结晶或新的物理机制。不得承诺“无真实缺陷”或“完全恢复未测取向”。

## 当前工作区的已验证入口和适用限值

以下路径和验证证据属于历史工作区。跨项目使用时，先从当前任务解析实际工作区根目录；不要把历史绝对路径或其中的产物当成通用位置。

- `03_tools/scripts/run_mtex_aztec_standard.ps1`：标准显示入口，参数为 `-InputPath`、`-OutputDirectory`，可选 `-OutputPrefix`。独立 CTF 可直接输入；CPR 需同名 CRC + CTF。仅渲染，不自动降噪或补点。
- `03_tools/scripts/run_aztec_ipf_match.ps1`：保留原 Map_006 复现入口。
- `03_tools/scripts/AztecMapExporter.cs` 和 `build_aztec_map.ps1`：本机公开原生接口提取与构建。
- `03_tools/scripts/mtex_export_aztec_exact.m`：已参数化网格、横纵步长、BC 范围、图层索引和输出命名；独立执行 MTEX 几何、BC 混合、边界绘制与读回验收。
- `05_evaluation/aztec_ipf_match_20260913/README.md` 和 `final/verification.json`：原始 Map_006 实测结果和适用范围。
- `05_evaluation/mtex_standard_smoke_20260913/independent_smoke_audit.json`：独立 CTF、不同网格/步长/BC 的实测记录。
- `03_tools/scripts/run_mtex_denoise_map006.ps1`：Map_006 专用降噪、补点、派生 CPR/CRC/CTF 和验证入口。结果说明与验收位于 `05_evaluation/mtex_denoise_Map_006_20260913/README.md`、`delivery_audit.json`；报告该次结果前读取实际审计且确认 `passed=true`，不能用显示基准的通过替代处理数据验收。

2026-09-13 已验证的是原始 Map_006：229×171、0.25 µm、39,159 点（35,844 已解析，3,315 未解析）、BC 21–249；MATLAB R2025a、MTEX 5.11.2、原生 core.ebsd 5.1.0.0。在 4 倍、916×684、1 输出像素边界线宽下，78,318 个邻接分类一致，PNG/TIFF 626,544 像素差异为零。该原始结果没有降噪或补点。

该次 BC 混合校准为 `BC8 = round_half_even(255*(BC-21)/228)`；已解析点 `floor((IPF8+BC8)/2)`，未解析点 `BC8`。该公式的限值及 50% 混合与当次配置相关，不能自动推断所有数据都相同。

独立 CTF 另已实际通过 6×4 网格、横纵步长 0.4/0.6 µm、BC 40–200 的原生/MTEX 渲染与 PNG/TIFF 读回，像素差异为零，源哈希未变，相元数据验证通过。这证明显示实现不再依赖 Map_006 的固定网格与 BC 常量，但不代表所有 EBSD 格式/项目都已覆盖。

Map_006 本次降噪交付审计亦已通过：原已解析点相对原 CTF 的取向变化均值 0.070527°、P95 0.248263°、最大 0.499898°，原已解析相邻点晶界分类改变 0；CPR/CTF 读回未解析点均为 0，其中 3,315 点（8.465%）是估计补点。补点空间留出验证相一致率 67.19%，相一致位置取向误差 P95 43.94°，因此 0.5° 保真上限不能延伸到孔洞真值。最终各格式 PNG 对自身原生参照均零差异；CPR 与 CTF 图之间实测 687 像素、最大通道差 2，应区分格式间舍入与各自原生匹配。全部数值仅属于该次 Map_006 处理。

当前支持范围：一个 dataset、完整均匀矩形网格（横纵各至少 2 点，横纵步长允许不同）、CTF CS0 约定、BC + 50% 逐点 IPF Z0 + 两类已配置 GB。读取实际 BC 范围；对不同透明度、额外图层、非矩形/非均匀网格、多 dataset 或不同坐标约定，现有保护会停止并需要针对性适配，不删除断言来绕过范围。其他数据逐次运行实际验证；输出到独立目录，不默认覆盖原始基准。Map_006 降噪参数仍是该数据的专用配方，不能因显示入口已参数化就自动应用到所有数据。
